# Code of conduct

This project is a place to get a piece of software installed, and to help
others do the same.

- Be respectful and patient. People arriving here are often stuck and
  frustrated with something that is not their fault.
- Keep discussion about the problem, not the person.
- Harassment, insults and discriminatory language are not acceptable, in
  issues, pull requests or anywhere else connected to the project.

Comments that break these rules may be edited or removed, and repeat
offenders blocked.

To report a problem, use GitHub's "Report content" option on the comment, or
contact the maintainer through the address on their GitHub profile.
